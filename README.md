# EcoTrack KZ 🇰🇿

## Project Concept
EcoTrack KZ is an open-source platform tailored for Kazakhstan to map illegal landfills, monitor air quality (AQI) in cities like Almaty and Astana, and locate the nearest recycling points for plastic, glass, and batteries.

## Problem & Solution
- **Problem**: Lack of transparent, real-time data on local environmental issues and low awareness of recycling infrastructure in Kazakhstan.
- **Solution**: A community-driven map where users upload photos of waste, and API integrations provide live air quality data.

## SDG Alignment
- **SDG 11**: Sustainable Cities and Communities (Improving urban waste management).
- **SDG 13**: Climate Action (Reducing emissions through better recycling).

## DPG Justification
EcoTrack KZ is a Digital Public Good because it uses an open-source license (MIT), protects user privacy, and addresses environmental challenges common in developing regions.
